# 自定义导航整理

入口：个人空间 → 自定义导航。私人链接仅归当前账号，不发布到站点内容库。

## 浏览和分类

- 默认每页 20 条，可切换为 50 条；搜索覆盖标题、完整网址、域名、摘要和分类名称，支持启用/停用状态筛选。
- 分类显示链接总数，分类名称支持搜索，每页显示 10 个；同名分类通过编号区分。分类和筛选数量包含停用链接。
- 关键词、分类、状态、页码、每页条数和管理视图写入 URL，可使用前进/后退和刷新。超出范围的页码显示最后有效页。
- 没有 JavaScript 时仍可浏览链接、通过原生 GET 表单筛选并分页；编辑、勾选整理和导入控件禁用并给出说明。

## 编辑与整理

- 默认显示紧凑卡片，点击编辑后打开单个独立表单。草稿不会直接修改列表数据；摘要、分类、状态、排序值均可编辑，原有分类图标保持。
- 保存中禁止重复操作。字段验证和网络错误保留填写内容；切换编辑、关闭或站内跳转前提示放弃未保存修改，刷新/离站使用浏览器原生未保存提示。
- 列表可刷新并保留草稿。另一处修改导航后，旧草稿的保存会拒绝；可在核对后明确载入最新记录，放弃旧草稿再编辑。
- 单页勾选、跨页与跨筛选勾选保留，每批最多 500 条。批量区显示全部勾选和当前筛选之外的数量。批量移动、启用、停用、删除均先列出完整记录，每页核对 10 条，明确确认后提交。
- 删除分类先展示将转为未分类的链接数量，只删除分类，保留链接。删除链接和分类无法撤销，不在正式站制造删除测试。
- 上移/下移链接调整同分类相邻顺序。排序由服务端计算，支持超过 500 条的完整集合；通过有界 JSON 分块整批更新排序，不再由浏览器发送全部 ID 或逐条写入。
- 书签导入收纳到折叠区；编辑或批量核对期间禁用导入，导入进行中或结果待核对期间禁用导航修改。

## 一致性和结果恢复

新版操作使用 `/api/user/navigation/workspace`，原导航接口保留兼容。服务端核对账号归属、正整数 ID、唯一选择、最多 500 条、完整操作内容和当前导航版本；POST 要求同源 Origin、JSON，流式请求体最多 256 KiB。

所有操作先生成只读核对，提交在 15 分钟内有效。写入前再次核对完整私人导航快照，分类、链接变更与完成回执在同一 D1 原子批次中完成；不支持原子批次时拒绝操作。在线核对最多每表 20000 行，合计 8 MiB、最多 20 个状态核对分块，超过范围在写入前拒绝。

浏览器只在当前账号的会话中保存 UUID 批次和摘要，不保存草稿、标题、网址或文件。响应丢失、格式不完整、错误未明确返回 `uncertain:false` 时保留待核对状态并禁止重新修改；刷新后查询本人的完成回执。未查到回执不能证明失败，可以显式取消未执行批次来阻止迟到请求，已完成批次返回原结果。不会自动重发修改请求。

回执位于 `settings` 的 `user:navigation:` 命名空间，仅保存摘要、状态、处理数量和时间；便携站点配置备份排除该命名空间，恢复时保留，上传备份不得注入回执。无新增依赖、迁移、Cron 或生产绑定。

## 验证

`npm run test` 验证真实 SQLite 原子回滚、账号隔离、并发状态拒绝、回执重放、取消和 601 条链接排序。`npm run test:navigation-workspace` 在隔离本地 Worker/D1 上验证实际页面和操作、跨页筛选、草稿保留、恢复流程、原生只读浏览及中文明暗布局。正式站仅做只读验收。
