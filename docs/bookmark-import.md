# 浏览器书签导入

入口：个人空间 → 自定义导航 → 导入浏览器书签。导入仅添加当前账号的私人导航链接，不发布到站点内容库。

## 使用流程

1. 选择 Chrome、Edge、Firefox 或 Safari 导出的 UTF-8 HTML 文件。
2. 生成预览，查看可导入、已有书签、文件内重复、无效条目和首批超限条目。支持搜索、每页 20 条浏览与跨页勾选；每批最多选择 500 条。
3. 为所选文件夹选择已有分类、新分类或未分类。文件夹路径是可修改的单个分类名称，不自动构建多级分类。同名的多个已有分类必须通过编号明确选择。
4. 修改勾选或分类后更新预览，再确认导入。导航在别处变化或预览超过 15 分钟时需重新核对；可重新生成预览以重置旧选择。
5. 导入完成后显示本批次书签和分类数量。重新预览同一文件可处理剩余书签。

文件上限为 2 MiB、5000 个链接条目；超过条目数会拒绝整个文件，不静默截断。单个网址最多 2048 个字符，文件夹路径最多 512 个字符、64 层。无效项目只列出原因，不执行其中的 HTML、脚本或链接。预览不发起网址请求。

去重以完整规范化网址比较，包括停用的已有书签。域名大小写和根路径规范化，保留查询参数、片段和非根路径尾斜杠。文件内重复项不自动替换首项；原有书签不被覆盖。

## 失败与结果核对

导入前会在当前账号的浏览器会话中保存批次编号与预览摘要，不保存源文件、网址或密钥。分类、书签和完成回执在同一个 D1 原子批次中写入；不支持原子批次的数据库会拒绝导入。写入时再次核对完整私人导航状态，拒绝迟到变更。

响应丢失或格式不完整时，页面保留待核对批次，阻止重新开始导入。刷新后自动读取本人的批次结果；没有完成记录不代表原请求不会到达。用户可以显式取消未开始的批次，取消记录会阻止迟到的同批次请求；已经完成的批次返回原结果，取消不会删除已添加书签。网络异常不触发自动重发。

回执保存在 D1 `settings` 的 `user:bookmark-import:` 保留命名空间，仅包含摘要、状态、数量与时间。便携站点配置备份排除此命名空间，恢复时保留回执，上传备份不得注入此类运行键。无数据库迁移、生产绑定或 Cron 变更。

## 验证

`npm run test` 包含解析、完整预览、分类归属、状态变化、原子回滚、丢失响应与批次重放测试。`npm run test:bookmark-import` 使用脚本自建的隔离本地 D1/Worker，验证真实页面、结果恢复、账号隔离、上限及中文明暗布局；不会使用正式书签制造测试结果。

## 接口约定

- `POST /api/user/navigation/import/preview` 接受 HTML、可选勾选编号和分类对应，返回完整预览及摘要。需要登录、同源 Origin 和 JSON，原始请求体最多 4 MiB。
- 原 `POST /api/user/navigation/import` 改为受保护提交：需当前预览时间与摘要、勾选和分类对应、UUID 批次编号以及显式确认。仅提供旧 `html` 字段会返回 428，不再直接写入。
- `GET /api/user/navigation/import?runId=...` 只返回当前账号的批次回执；不存在时返回 null。`POST` 的 `action=cancel` 分支需显式确认，登记或读取原批次结果。
- 只有服务端明确返回 `uncertain: false` 的失败才能解除待核对状态。非 JSON、格式不完整、未说明确定性的错误、超时或网络中断均保留恢复标记。
- 在线核对范围最多每表 20000 条私人导航记录、合计 8 MiB，并受原子状态核对的 20 个分块上限保护；超过范围在写入前拒绝，不降级成逐条导入。
