# NaviNest 公共界面规范

参考 [形色场 UI Handbook](https://zzhzhouzhou.github.io/UI-handbook/)，结合网址导航的内容密度制定。本文是项目内的具体约定，后续公共页面与组件沿用这些规则。

## 视觉基础

颜色、间距、圆角、控件高度、动画和层级由 `src/routes/design-tokens.css` 管理；公共组件样式由 `src/routes/ui-foundation.css` 管理。既有 `--nav-*` 变量映射到同一套令牌。

| 项目 | 约定                                                                                          |
| ---- | --------------------------------------------------------------------------------------------- |
| 颜色 | 中性背景与卡片；红色用于品牌、当前入口、主要操作；成功与错误同时提供文字或图标                |
| 文字 | 辅助 13px、正文 15px、卡片/分类 16px、主区块 22px、侧栏标题 18px、页面 32px；中文系统字体优先 |
| 间距 | 使用 4 / 8 / 12 / 16 / 24 / 32px；先保证标题阅读空间，再决定列数                              |
| 圆角 | 小控件 6px，卡片 12px，覆盖层 16px                                                            |
| 触控 | 主要操作与手机入口使用至少 44px 的可点区域；不靠缩小点击范围提高密度                          |
| 层级 | 普通内容 0，悬浮信息 10，固定头部 40，底栏 45，遮罩 50，抽屉 51，提示 60，跳转入口 70         |
| 深色 | 替换语义令牌；背景、正文、辅助文字、输入框、抽屉和提示均单独检查                              |
| 动效 | 小反馈约 150ms，覆盖层约 220ms；尊重减少动态效果偏好                                          |

正文与辅助文字的目标对比度为 4.5:1，控件边界与焦点清晰可辨。具体的卡片颜色属于内容标识，避免把所有内容类型做成大面积彩色背景。

文字同时按字号、字重与颜色分层：区块标题使用 700 字重，卡片标题使用 600 字重和标题色；分类导航使用 500 字重，选中项提升为 600；正文、热榜和辅助信息使用 400 字重。标题色在浅色主题接近黑色，在深色主题切换为亮色。辅助文字保持可读对比度，避免使用透明度把文字变淡。

首页卡片最小宽度为 260px；窄屏不足时使用可用宽度，自动减少列数。公共首页内容画布最大宽度为 1800px。首页卡片按“标题 → 用途”显示，不展示“网址、软件、文章、书籍、公告”等内容类型文字标签及浏览/收藏条目计数，不为已删除的标识保留空行。首页标题和一行用途共用至少 44px 的原生详情链接，卡片最小高度 80px、上下各 8px 留白；公共结果卡片和独立排行条目同样删除类型文字标签，公共结果仍保留真实内容标签及用途简介；后台数据展示沿用现有约定。空简介不占行，不编造用途。网格保留空轨道，避免稀疏内容把单条卡片拉满整行。优先保证文字阅读空间，避免用小字号塞入更多列。

首页网格行距为 8px，分类区块间距为 16px。分类标签多时只在标签区域横向滚动；620px 以下放在标题下一行，手机标签至少 44px 高。不能让标签数量撑宽页面或挤掉“更多”。

## 组件交互

- 标题链接进入内容详情；访问箭头经过安全跳转页，在新标签页打开。二者保持独立链接，支持浏览器原生键盘和新标签页操作。
- 紧凑卡片在悬停或标题获得键盘焦点时，显示完整标题、简介与操作说明。手机端保留访问入口与足够的点击范围。
- 首页与结果页使用同一个搜索表单。空关键词不能提交；输入后可以清空并恢复输入焦点；搜索期间显示忙碌状态。
- `/` 或 `Ctrl / ⌘ K` 聚焦当前搜索框。在输入、选择、富文本编辑或模态菜单中，不抢占键盘输入。
- 搜索引擎使用带按下状态的按钮组，记住最近选择；已删除/停用偏好或存储失败回到有效默认源，不影响搜索。推荐词标注“推荐搜索”，来自现有搜索模块配置，点击时使用当前搜索源，不虚构热度；留空隐藏。多词仅在推荐词区域横向滚动，末项键盘可达，不撑宽页面。
- 站内搜索按标题完全匹配、前缀、包含、用途摘要、分类/标签名称排序；显示完整总数，每页 24 条。分页为原生链接，保留查询与页码，新查询重置第一页；当前页明确标识，较多页码使用省略号，所有翻页目标至少 44px，窄屏可换行。
- 分类页内标签保留各自筛选逻辑，导航定位规则沿用现有回归检查。
- 手机抽屉打开后焦点进入关闭按钮，背景不可聚焦；Tab 与 Shift+Tab 在抽屉内循环。Escape、关闭按钮或遮罩关闭后恢复触发按钮焦点；切回桌面宽度自动关闭。
- 普通与成功提示默认短暂展示；错误默认保留到手动关闭。所有提示都使用明确的关闭按钮，成功与错误分别通过状态和警报区域反馈。
- 空列表解释当前情况并提供返回首页或浏览分类的下一步；网络导航继续使用全局加载反馈。

## 验证

`npm run test:home-layout` 覆盖分类锚点定位、首页 12 种布局，以及首页、搜索结果、空结果和详情页的 24 种浅色/深色布局与手机焦点控制。另有 320、375、1366、1920、2560px 的 10 组浅色/深色布局，检查用途可见性、类型文字标签及空辅助行缺席、稀疏列宽、长中文/英文及首页计数节点缺席，以及五类排行详情与安全访问入口。新增组件继续检查 320px 宽度下无水平溢出、可见键盘焦点、搜索行为与主题对比度。新增 30 条资源和 30 个分类标签的 10 组密集布局，验证单屏密度、44px 详情点击区、用途点击及末项键盘滚动可达。CI 使用可用中文字体并保存正常/边界/密集截图。

搜索基础优化新增 18 组布局：320、375、1366、1920px 的浅色/深色大页数分页、8 个长中文推荐词与 375/1366px 后台文本框；完整检查共 74 组，保存 62 张截图。搜索源持久化、失效/禁用源回退、存储不可用、推荐词按当前源跳转、新查询重置页码及分页键盘/历史操作另有行为检查。大量结果的浏览器检查使用实际组件 SSR 夹具，D1 查询与完整分页使用真实 SQLite 集成测试，不作为线上部署验收。

后台单次登录另外增加 320/1366px 浅色/深色的 4 组真实登录页检查：中文标题、原后台地址传递、GitHub 暂停后的入口/空分隔线缺席与旧授权地址拒绝、原生 POST 表单、44px 控件、键盘顺序与无横向溢出。完整脚本合计覆盖 78 组布局；正式后台会话与角色授权由真实 SQLite 及路由测试验证，线上 Access 切换需单独验收。

本轮完善现有公共页面与交互。高级命令面板、粒子背景、复杂转场等，按具体使用场景单独设计。
